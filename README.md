# LexBridge

On 1 July 2024 India replaced the Indian Penal Code with the Bharatiya Nyaya Sanhita.
Every section number changed (IPC 420 is now BNS 318(4)), and which code applies
depends on the date of the offence.

LexBridge answers questions about either code. It works out which law applies from
the date, retrieves the exact provision, and cites it. When it can't do that, it
asks for the missing detail or says it doesn't know. It never makes up a section number.

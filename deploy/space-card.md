# LexBridge

On 1 July 2024 the Bharatiya Nyaya Sanhita (BNS) replaced the Indian Penal Code (IPC), and
every section number changed. Which code applies depends on when the offence was committed.

Ask in plain words. LexBridge routes the question by date, retrieves the provisions, and
answers with citations; every section number in the answer is checked against the sources,
and it asks for the date rather than guess.

General information, not legal advice. Do not include personal details in questions.
